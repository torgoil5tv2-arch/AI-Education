## Фізика

- **Сильні сторони**:
  - Базові задачі на рух (v = s/t, s = v·t, t = s/v) з простими числами

  - Помилки уваги на множенні (повторюються)
  - Під тиском плутає формули: I=P/U vs I=U/P

## Програмування

- **Сильні сторони**:
  - Логічне мислення, вміння аналізувати умови
  - Мотивація до спеціальності 122 «Компʼютерні системи»
  - Розуміє логіку if/else самостійно
  - Чесно визнає незнання
  - Правильно визначає, яка гілка спрацює в простому if / elif / else
  - Уже не плутає основну межу 18
  - Дає правильні усні відповіді по результату коду

- **Слабкі місця**:
  - Неуважне читання коду (пропускає оператори)
  - range(n) — не знав початку з 0
  - Формулювання ще неточні, особливо про "умову" і "гілку"
  - Практичного написання коду ще не було
  - Потрібно автоматизувати розуміння, а не тільки відповідати усно

- **Рівень по темі**: Програмування: 5.5/10

- **Поточний фокус** (наступні 1–3 заняття):
  - Перейти до простих задач з input() + if/else
  - Додати 1 задачу з elif
  - Перевірити самостійне написання короткої програми без підказки

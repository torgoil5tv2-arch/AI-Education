# LEARNING PLAN — Максим, 9 клас
> 6-тижневий інтенсив до рівня 9.5/10

---

## 1. Загальні цілі

- Поточний рівень: ~6/10.
- Ціль на вступ: мінімум 7.5/10, робоча ціль — 9.5/10.
- Предмети:
  - математика (алгебра + геометрія),
  - фізика (механіка + електрика),
  - програмування,
  - логіка (усна співбесіда).
- Формат: ~1 година на день, 5–6 днів на тиждень.

---

## 2. Структура одного заняття

Кожен урок (≈ 60 хв) має однаковий шаблон:

1. Терміни (3–7 слів) + короткі питання на розуміння.
2. Теорія (коротко) + 1–2 базові приклади.
3. Відео (1 посилання) + завдання: що нового / що незрозуміло.
4. Опитування по відео (3–5 запитань по змісту).
5. Практика: 2–3 прості задачі + 2–3 складніші.
6. Міні-тест: 3–6 задач змішаного типу.
7. Фіксація прогресу + блок [LESSON_LOG] для Агента.

---

## 3. План на 6 тижнів (огляд)

### Тиждень 1 — Відсотки + повтор квадратних рівнянь

Фокус:
- закрити тему відсотків (з нуля до автоматизму),
- освіжити дискримінант і корені квадратних рівнянь.

Дні:
- День 1: відсоток числа, число за відсотком.
- День 2: збільшення/зменшення на p%, знижки, націнки.
- День 3: змішані задачі на відсотки (зарплата, покупки, відсотки по вкладу).
- День 4: повтор D і формули коренів (4–5 рівнянь).
- День 5: міні-тест по відсотках + 1–2 задачі на D.

### Тиждень 2 — Корені + Геометрія 1

Фокус:
- перестати «боятися» коренів,
- вивчити базові формули площ.

Дні:
- День 1: спрощення коренів (розкладання підкореневого, типу √20, √45, √72).
- День 2: вирази з коренями (сума, різниця, множення).
- День 3: площа прямокутника і трикутника, 4–6 задач.
- День 4: площа круга, довжина кола, 4–6 задач.
- День 5: міні-тест по коренях + площах.

### Тиждень 3 — Геометрія 2 + комбіновані задачі

Фокус:
- теорема Піфагора,
- задачі, де змішується алгебра й геометрія.

Дні:
- День 1: теорема Піфагора (основа + прості задачі).
- День 2: діагоналі прямокутника, висота в прямокутному трикутнику.
- День 3: задачі «з життя» (драбина до стіни, відстань по діагоналі тощо).
- День 4: комбіновані задачі (площа + алгебра).
- День 5: міні-тест по геометрії (Піфагор + площі).

### Тиждень 4 — Фізика: механіка + одиниці

Фокус:
- v, s, t на рівні автомату,
- знання одиниць і вміння перевіряти розмірності.

Дні:
- День 1: v = s/t, прості задачі на один об’єкт.
- День 2: s = v·t, t = s/v, задачі на порівняння.
- День 3: рух двох тіл (назустріч, в одному напрямку).
- День 4: одиниці вимірювання (м, с, м/с, Н, Дж, Вт), проста практика.
- День 5: міні-тест по механіці + одиницях.

### Тиждень 5 — Фізика: електрика + діагностика програмування

Фокус:
- базовий закон Ома і потужність,
- первинна оцінка рівня програмування.

Дні:
- День 1: I = U / R, задачі на знаходження I, U, R.
- День 2: потужність P = U·I, задачі на лампочки та енергоспоживання.
- День 3: змішані задачі по електриці.
- День 4: діагностичний блок з програмування (if, max з 3, цикл, сума/мінімум у масиві).
- День 5: продовження діагностики або розбір результатів.

### Тиждень 6 — Логіка + інтегрований міні-екзамен

Фокус:
- формальний запис логічних рішень,
- перевірка всіх пройдених тем одним екзаменом.

Дні:
- День 1: логічні задачі (коробки, послідовності) з повним записом «якщо — то».
- День 2: логічні задачі (правдомови/брехуни), формалізація.
- День 3: пробний екзамен (математика + фізика + логіка + прості задачі програмування).
- День 4–5: розбір помилок + додаткові задачі по найслабших темах.

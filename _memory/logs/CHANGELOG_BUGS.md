## [B001] 2026-05-10 — Плутанина підвищення/зниження у зворотних задачах

### Симптом
Максим писав 90% замість 110% у зворотних задачах з підвищенням.

### Причина
Плутанина напрямку операції при перекладі тексту задачі в математичну модель.

### Пастка
Знижка логічно зрозуміліша ("відкинути"), а підвищення часто сприймається як просто "додати до поточного", забуваючи що база 100% змінилась.

### Рішення
```
Відпрацювати таблицю: знижка X% → залишилось (100-X)%, підвищення X% → стало (100+X)%
```

### Правило
Для зворотних задач з підвищенням завжди починати запис з "було 100%, стало 100%+X%".

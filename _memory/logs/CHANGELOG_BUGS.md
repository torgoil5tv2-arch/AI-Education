### Симптом
Що ламалось з точки зору поведінки (не коду).

### Причина
Технічна причина — чому код був неправильний.

### Пастка
⚠️ Неочевидний момент — чому fix не тривіальний.
Якщо не було — написати "Відсутня".

```

```

# SESSION-2026-05-22 — if / elif / else: читання логіки умов

## Коротко
Первинна діагностика умовних операторів у Python. Максим розібрався в різниці між if, elif та else, навчився передбачати результати розгалужень усно, проте практичне написання коду ще попереду, а термінологія потребує уточнення.

## Тиждень плану / підтема
Тиждень 4 — діагностика програмування / if / elif / else: читання логіки умов

## Що пройшли
- Пояснили різницю між if, elif і else.
- Розібрали, що elif перевіряє наступну умову після хибного if.
- Відпрацювали приклад з віком: 18, 17, 13, 20.
- Закріпили, що Python виконує тільки першу істинну гілку.

## Успіхи
- Правильно визначає, яка гілка спрацює в простому if / elif / else.
- Уже не плутає основну межу 18.
- Дає правильні усні відповіді по результату коду.

## Слабкі місця
- Формулювання ще неточні, особливо про “умову” і “гілку”.
- Практичного написання коду ще не було.
- Потрібно автоматизувати розуміння, а не тільки відповідати усно.
